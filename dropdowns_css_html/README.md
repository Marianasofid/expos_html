# Dropdowns en CSS

## ¿Qué es un Dropdown?

Un Dropdown o menú desplegable es un elemento de una página web que permite mostrar una lista de opciones cuando el usuario pasa el cursor sobre un botón o elemento.

Los Dropdowns son útiles para organizar las opciones de una página y ahorrar espacio.

## ¿Cómo funciona?

En CSS, las opciones del menú normalmente permanecen ocultas y aparecen cuando el usuario pasa el cursor sobre el elemento principal. Para esto se utiliza principalmente el selector `:hover`.

### Propiedades principales

- `display: none;` → Oculta el menú.
- `display: block;` → Muestra el menú.
- `position: absolute;` → Permite posicionar el menú.
- `:hover` → Hace que el menú aparezca al pasar el cursor.

## Importancia

Los Dropdowns permiten crear páginas web más **organizadas, sencillas y fáciles de navegar**, especialmente cuando existen varias opciones dentro de un mismo menú.
